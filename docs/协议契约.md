# SongLink 点歌台 · 通信协议契约 v1

- 版本：`v:1`（协议主版本，向后不兼容时递增）
- 适用：`SongLink Remote`（安卓）↔ `SongLink Host`（Windows）
- 关联：架构文档 §6.5 / §14.3；机器可读 Schema 见 `schema/songlink-frame.schema.json`
- 编码：UTF-8；文本帧为 JSON；音频为二进制分片

---

## 1. 传输与分帧

| 通道 | 载体 | 承载内容 | 说明 |
|---|---|---|---|
| 局域网（主） | WebSocket（TCP，wss 可选） | 全部 JSON 帧 + 二进制音频分片 | 富数据首选；二进制帧用 WebSocket binary message |
| 局域网音频（可选低延迟） | UDP（RTP 式分片） | 音频负载 | 与 WS 并存，`audio:start` 协商端口 |
| 蓝牙（辅） | RFCOMM(SPP) 或 BLE GATT 特征 | 指令子集 + 文本歌词 + 配对引导 | 无 Wi-Fi 兜底；不传封面/音频 |

- 每个 JSON 帧 = 一条完整消息（WS 一个 text message 一帧；蓝牙按换行 `\n` 分帧）。
- 心跳：`ping`/`pong`，间隔 3s，超时 2 次判离线并触发降级（见 §7.2）。

## 2. 通用信封（Envelope）

所有帧共享字段：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `v` | int | ✅ | 协议主版本，固定 `1` |
| `type` | string | ✅ | 帧类型（见 §3） |
| `seq` | int | ✅ | 发送方单调递增序号，用于断线补发与去重 |
| `id` | string | 部分 | 命令帧的请求 ID，供 `ack`/`error` 回填 `ref` |
| `ts` | number | 可选 | 发送方 Unix 毫秒时间戳（音频/进度同步用） |
| `sig` | string | 可选 | HMAC-SHA256(`token`, canonical(frame 去 sig)) 十六进制；开启强制验签时入站 `cmd` 必带（§6） |

## 3. 帧类型

### 3.1 `hello`（握手/能力协商/鉴权）
```jsonc
{ "v":1,"type":"hello","seq":1,"id":"h1","role":"remote","device":"Pixel-7","os":"Android 14",
  "caps":["cmd","state","lyric","art","audio"], "pin":"246810" }
```
- `role`: `remote` | `host`。
- `caps`: 该端能收发的能力；Host 据此裁剪推送（蓝牙模式 `caps` 不含 `art`/`audio`）。
- `pin`: 首次配对时携带 Host 显示的 6 位 PIN；`token`: 重连时携带上次下发的令牌（二者其一有效即通过）。

### 3.1b `authResult`（鉴权回执，Host→Remote）
```jsonc
{ "v":1,"type":"authResult","seq":2,"ref":"h1","ok":true,"token":"FE39C685…" }
{ "v":1,"type":"authResult","seq":2,"ref":"h1","ok":false,"code":"AUTH_FAILED" }
```
鉴权规则（评审 #6）：连接建立后**只允许发 `hello`**；PIN/token 校验通过则置该连接为已鉴权、下发长期 `token`、并回 host `hello` + 当前 `state`；未鉴权连接发其它帧一律回 `error:AUTH_FAILED`，且**不会收到任何 state/lyric/event 广播**（防信息泄露）。

### 3.2 `cmd`（指令，Remote→Host）
```jsonc
{ "v":1,"type":"cmd","seq":7,"id":"c-17","action":"pick","args":{"title":"晴天","artist":"周杰伦"} }
```
`action` 枚举：

| action | args | 说明 | 依赖能力 |
|---|---|---|---|
| `play` `pause` `toggle` `stop` `next` `prev` | — | 传输控制 | T1 |
| `volume` | `{level:0-100}` | 音量 | T1 |
| `search` | `{kw}` | 搜索（Host 回 `searchResults`，评审 #5 已实现） | T3 |
| `pick` | `{title,artist,album?,trackId?}` | 点歌 | T3 或 T2 |
| `queue.add` `queue.remove` `queue.top` `queue.clear` | 见 §3.6 | 队列 | — |
| `import` | `{name,mime}` | 声明要导入的音源（配合 HTTP 上传） | T2 |
| `setSourceMode` | `{mode:"PC_LOCAL"|"PHONE_STREAM"}` | 音源模式切换 | T5 |
| `calibrate` | `{lyricOffsetMs, title?, artist?}` | 歌词毫秒校正（评审 #11 已实现）；带 title/artist 为该曲偏移，省略则全局。Host 存偏移并立即重发当前歌词 | — |

> `search` 依赖适配器的 `Search` 能力（§6.1 Caps）；不支持时 Host 回 `error:SEARCH_UNAVAILABLE`，支持则回 `searchResults`。

### 3.2b `searchResults`（搜索结果，Host→Remote）
```jsonc
{ "v":1,"type":"searchResults","seq":9,"ref":"c-17","query":"Yellow",
  "results":[{"title":"Yellow","artist":"Coldplay","album":"Parachutes","dur":267}] }
```
`ref` 回填发起 `cmd:search` 的 `id`；`results` 为命中列表（可为空）。

### 3.3 `ack`（回执，Host→Remote）
```jsonc
{ "v":1,"type":"ack","seq":8,"ref":"c-17","ok":true }
```

### 3.4 `state`（当前播放真值，Host→Remote 广播）
```jsonc
{ "v":1,"type":"state","seq":20,
  "now":{"title":"晴天","artist":"周杰伦","album":"叶惠美","pos":12.3,"dur":269,"status":"playing","artRef":"img:a1","sourceMode":"PC_LOCAL"} }
```
- `status`: `playing|paused|stopped|buffering`。
- `pos`/`dur` 秒；采样 ~4Hz，Remote 本地按墙钟插值。
- `PHONE_STREAM` 模式下该 `state` 由手机侧 `srcMeta` 驱动（见 §3.8）。

### 3.5 `lyric`（整首一次下发）
```jsonc
{ "v":1,"type":"lyric","seq":21,"trackId":"a:晴天-周杰伦","offsetMs":0,
  "lines":[{"t":0.0,"x":"首句"},{"t":3.7,"x":"第二句"}] }
```
- `t` 秒；`x` 文本；`offsetMs` 全局校正。换曲才重推。

### 3.6 `event`（队列/模式变更）
```jsonc
{ "v":1,"type":"event","seq":22,"name":"queue-updated",
  "queue":[{"trackId":"...","title":"...","artist":"...","by":"手机A"}] }
{ "v":1,"type":"event","seq":23,"name":"source-mode-changed","mode":"PHONE_STREAM" }
```

### 3.7 `art`（封面引用，非内联）
```jsonc
{ "v":1,"type":"art","seq":24,"ref":"img:a1","mime":"image/jpeg","size":48213 }
```
- 大图经 HTTP `GET /art/{ref}` 拉取（局域网），不进帧内；蓝牙模式不下发 `art`。

### 3.8 `srcMeta`（串流模式手机上报元数据，Remote→Host）
```jsonc
{ "v":1,"type":"srcMeta","seq":30,"ts":1730000000123,
  "title":"...","artist":"...","pos":5.2,"dur":240,"status":"playing","artRef":"img:x" }
```

### 3.9 `audio:start` / `audio:stop`（串流会话）
```jsonc
{ "v":1,"type":"audio:start","seq":31,"codec":"opus","rate":48000,"ch":2,"frameMs":20,"port":51000 }
{ "v":1,"type":"audio:stop","seq":40 }
```
- 音频负载走 §1 的二进制通道，每片带 `seq`+`pts`（见 §4）。

### 3.10 `error`
```jsonc
{ "v":1,"type":"error","seq":41,"ref":"c-18","code":"PICK_UNSUPPORTED","hint":"请用 App 搜索后自动同步" }
```
`code` 枚举：`PICK_UNSUPPORTED` `APP_NOT_FOUND` `SEARCH_UNAVAILABLE` `LYRIC_NOT_FOUND` `ART_UNAVAILABLE` `CAP_DENIED` `MODE_CONFLICT` `DRM_CAPTURE_BLOCKED` `AUTH_FAILED` `BAD_PROTO` `RATE_LIMITED`。

## 4. 音频二进制分片格式（`PHONE_STREAM`）

每片（UDP 或 WS binary）：

```
+--------+--------+---------+---------+------------------+
| ver(1) | flags  | seq(4)  | pts(8)  | payloadLen(2)    | opusFrame... |
+--------+--------+---------+---------+------------------+
```
- `ver=1`；`flags`：bit0=首片/关键帧，bit1=末片。
- `seq` 用于丢帧检测；`pts` 为 90kHz 或采样帧号。
- 默认 Opus 48kHz/立体声/20ms；`audio:start` 协商覆盖。

## 5. 版本与兼容

- 未知 `type` 必须忽略（前向兼容）；未知 `action` 回 `error:BAD_PROTO`。
- `v` 不匹配 → 拒绝并回 `error:BAD_PROTO`。
- 新增字段用可选，不改语义。

## 6. 安全

- 配对：首次 LAN 直连用 Host 显示的 6 位 **PIN**（`hello.pin`）；或蓝牙带外交换 LAN 地址+PIN（§6.6 架构）。
- 鉴权：PIN 通过后 Host 下发长期 `token`（`authResult.token`），重连用 `hello.token` 免再输 PIN。
- 连接级鉴权门：连接未鉴权前只允许 `hello`；其余帧回 `error:AUTH_FAILED`，且不接收任何广播（评审 #6）。
- 完整性（已实现，评审 §6）：签名模式（`requireFrameSig`，默认关）开启时——**入站** `cmd` 由客户端用连接 `token` 盖 `sig`，Host 校验，缺失/错则回 `error:AUTH_FAILED`；**出站**广播帧（state/lyric/event）由 Host 用 `hostKey` 盖 `sig`，`hostKey` 经 `authResult.hostKey` 下发，客户端据此验证 Host 帧未被伪造/篡改。`sig = HMAC-SHA256(key, canonical(frame 去 sig))`。蓝牙侧默认不签。
- 传输加密（待实现）：wss 推荐；纯局域网 http 场景至少 token+sig。

> 实现状态：PIN 配对、token 重连、连接级鉴权门、未鉴权不广播、**每帧 HMAC 入站验签 + 出站签名** —— 均已落地并有 selftest/契约测试覆盖（`FrameSigner` 纯逻辑 + HostServer 强制验签/出站签名集成）；wss 为后续加固项。

## 7. 时序约束

- `cmd`→`ack` 期望 < 300ms（局域网）/ < 1.5s（蓝牙）。
- `state` 广播：变化即时 + 稳态 ≤1Hz 心跳（评审 #3 去抖）；`lyric` 仅换曲时；`art` 拉取异步。
- 断线重连：Remote 在 `hello.lastSeq` 带上已见的最大 seq；Host 维护有界重放缓冲（state/lyric/event），补发 `seq > lastSeq` 的广播（**已实现**，评审 §7）；点对点帧（ack/error/authResult/searchResults）不补发，客户端按 seq 去重。
