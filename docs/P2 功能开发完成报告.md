### **3️⃣ 播放历史记录导出** ✅ 完成

| 交付物 | 文件路径 | 说明 |
|--------|----------|------|
| **数据模型** | `app/src/main/java/songlink/remote/data/PlaybackHistory.kt` | PlayedSong 数据结构 + HistoryManager |
| **UI 页面** | `app/src/main/java/songlink/remote/ui/history/HistoryPage.kt` | LazyColumn 列表 + 确认对话框 |
| **Excel 工具** | `HistoryExcelExporter` | Apache POI 集成框架 |

**核心功能：**
1. **自动记录**
   - 每次播放自动添加到历史列表
   - 最多保留最近 100 条记录
   - 包含歌曲名、艺人、时间戳

2. **可视化展示**
   ```
   ┌─────────────────────────────┐
   │ 晴天 · 周杰伦                │
   │ 2026-10-12 14:30:15         │
   └─────────────────────────────┘
   ```

3. **导出 Excel (.xlsx)**
   - 一键导出全部历史记录
   - 列格式：时间 | 歌曲 | 艺人 | 专辑 | 时长
   - 确认后清空本地记录

4. **UI 交互**
   - 顶部工具栏：导出按钮 + 清空按钮
   - 空状态提示："暂无播放记录"
   - 按时间倒序排列（最新在前）

**Apache POI 依赖：**
```xml
<dependency>
    <groupId>org.apache.poi</groupId>
    <artifactId>poi-ooxml</artifactId>
    <version>5.2.3</version>
</dependency>
```

### **4️⃣ Web Admin 音频频谱可视化** ✅ 完成

| 交付物 | 文件路径 | 说明 |
|--------|----------|------|
| **HTML 模板** | `apps/web-admin/spectrum.html` | 暗黑风格 UI + Canvas 画布 |
| **JS 逻辑** | `apps/web-admin/spectrum.js` | Canvas API + requestAnimationFrame |

**视觉特性：**
- 🌈 **渐变彩色条**: Purple → Pink → Blue → Green
- ⬇️ **圆角设计**: 每条柱顶部圆角 4px
- 💡 **动态效果**: 平滑动画 60 FPS
- 📊 **实时统计**: 
  - 频段数：64
  - 刷新率：60 FPS
  - 当前音量：百分比显示

**功能亮点：**
1. **模拟频谱动画**
   - 64 个频段频率波动
   - 正弦波函数模拟真实音频响应
   
2. **Volume Meter**
   - 左上角实时音量百分比
   - 蓝色填充进度条 (0-100%)

3. **交互控制**
   - 开始/暂停按钮：toggleSimulation()
   - 切换模式按钮：反转配色方案

4. **响应式设计**
   - 自适应窗口大小变化
   - DPR 高清屏优化（@2x / @3x）

**技术栈：**
- Vanilla JS (无框架)
- Canvas 2D Context
- requestAnimationFrame
- CSS Grid + Flexbox
